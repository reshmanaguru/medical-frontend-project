# MediCare Hospital - Frontend

A modern, responsive, and beautifully designed single-page static hospital website built with HTML, CSS, and Bootstrap.

## 🚀 Live Demo

https://drmedicare.netlify.app/

## ✨ Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Modern UI/UX**: Clean layout with smooth hover effects and micro-animations.
- **Hero Section**: Engaging welcome screen with call-to-action buttons.
- **Services Overview**: Details about Cardiology, Orthopedics, Emergency Care, and more.
- **Doctors Profile**: Cards featuring specialist doctors with social media links.
- **Statistics Counter**: Animated number counters displaying hospital metrics.
- **Contact/Appointment Section**: Easy-to-use form for booking appointments.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling and hover effects.
- **Bootstrap 5.3**: Layout and responsive grid system.
- **Bootstrap Icons**: Scalable vector icons.
- **AOS (Animate On Scroll)**: Smooth scroll animations.
- **Google Fonts**: Custom typography using 'Poppins'.
